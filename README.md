# Floating Particles Button — React

Projeto exportado do Figma e organizado para uso com React + TypeScript + Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite no terminal.

## Estrutura

- `src/App.tsx` — aplicação principal
- `src/main.tsx` — entrada do React
- `src/components/` — componentes React
- `src/assets/` — imagens e assets
- `src/index.css` — estilos globais
- `package.json` — dependências e scripts

O código visual original foi preservado para evitar alterações involuntárias no layout exportado pelo Figma.
